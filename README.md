## ⚡ 快速开始

### 三步完成分析

1. **粘贴数据** - 复制粘贴 CSV/Excel 数据
2. **配置指标** - 自动识别算法、指标，灵活配置优化方向
3. **一键分析** - 获得完整统计结论、可视化图表和决策建议

### 数据格式示例

```csv
Case,#Size,Base/latency,New/latency,Base/accuracy,New/accuracy
case01,1000,120,110,0.85,0.88
case02,2000,240,220,0.78,0.80
case03,1500,180,190,0.82,0.81
```

## 🐍 Python SDK

想要自动化分析？AlgoBench 提供 Python SDK，支持命令行和 Python 库两种方式调用。

```bash
pip install algobench-sdk
```

适合脚本自动化、CI/CD 集成和 AI Agent 调用。详见 [Python SDK 文档](./PYTHON_SDK.md)。

***

## 💻 命令行 CLI

单文件 CLI，一行命令把 CSV 文件变成浏览器里可分享的分析结果。**无需 npm install，下载即用，内网/无网可用**。

```bash
node algobench-cli.js open data.csv --baseline V1 --compare V2
```

支持 `open`/`share`（浏览器交互，纯 JS）和 `analyze`/`stats`/`quality`/`diagnose`/`validate`（数据分析，透传 Python SDK）。详见 [CLI 文档](./CLI.md)。
